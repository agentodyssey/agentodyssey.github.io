# Affiliation logos

Official artwork, stored locally so the homepage does not depend on external image hosts.

- `jhu-logo-white.svg`: `RGB (Digital)/SVG/JHU.logo_horizontal.white.svg` from the [Johns Hopkins University logo package](https://brand.jhu.edu/download-resources/primary-logo/). See the [primary logo guidelines](https://brand.jhu.edu/visual-identity/primary-logo/).
- `lambda-logo-white.svg`: [Lambda's official white logo](https://lambda.ai/hubfs/raw_assets/Lambda%20Marketing%20Website/143/js_client_assets/assets/logo-white-amFAN7ru.svg), as used on [lambda.ai](https://lambda.ai/).

The artwork is unmodified; the homepage controls display size while preserving each logo's proportions.
